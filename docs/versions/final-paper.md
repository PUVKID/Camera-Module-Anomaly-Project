# 📄 최종 원고

정상·불량 카메라 모듈 영상에 대한 YOLOv8·ViT·CNN 분류 비교 원고입니다.

[최종 원고 읽기](../../%EB%85%BC%EB%AC%B8/%EC%B5%9C%EC%A2%85_%EB%85%BC%EB%AC%B8.pdf) · [프로젝트 소개](../../README.md) · [연구 자료](../VERSIONS.md)

## 🔎 연구 범위

원고의 표·본문·그래프에는 일부 수치 차이가 있습니다. 평가는 모델별 분류 실험을 대상으로 하며, 외부 테스트와 생산라인 검증은 후속 과제입니다.

카메라 모듈 정상·불량 영상의 데이터 구성과 YOLOv8·ViT·CNN 분류 비교 결과를 최종 원고에 정리했습니다.


## 🧩 주요 내용

- 모델별 제조 결함 이미지 분류 결과를 비교합니다.
- 표·본문·그래프 간 일부 수치 차이를 보존하고 원문 지표 정의를 함께 확인합니다. 실행 코드·외부 시험 자료는 제공하지 않습니다.

## 🔄 자료 구성

이 저장소는 최종 원고 한 편을 공개합니다. 연구 방법과 처리 흐름을 원고에 정리했습니다.
