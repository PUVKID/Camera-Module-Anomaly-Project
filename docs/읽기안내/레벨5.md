<a id="guide-problem"></a>

## 문제와 주요 기능

학습 80%·검증 20% 분할 설명을 원고에서 확인합니다. 독립 외부 시험과 공정별 분포 이동 평가는 후속 과제입니다. 비교의 해석에는 분할 단위, 클래스 비율, 모델 선택 과정과 지표 산출 위치가 필요하며, 누락된 조건을 임의로 채우지 않습니다.

<a id="guide-flow"></a>

## 입력·처리·출력

YOLO의 imgsz64·batch32·3000epoch 상한·patience100은 원고의 호출 조건입니다. ViT의 google/vit-base-patch16-224-in21k와 CNN 전 처리 224×224를 같은 해상도로 환산하지 않습니다. 손실 수렴과 최종 평가 시점의 동일성은 원문 근거 범위에서만 판단합니다.

<a id="guide-practice"></a>

## 실험과 사용 흐름

검토 순서는 데이터 분할, 모델별 입력·초기화, 학습 종료 규칙, 표·본문·그림의 수치 대응입니다. 원고의 코드 조각은 실행 가능한 불변 실험 묶음과 다릅니다. 독립 재현의 필수 입력이 없는 상태와 문헌 검토를 구분합니다.

<a id="guide-results"></a>

## 관측 결과와 해석

원고 5 쪽 표·6 쪽 결론의 YOLO F1 0.972와 5쪽 본문 0.977은 별도로 유지합니다. 시간 그래프와 표의 일부 차이, ViT 조기 종료 적용/제거 서술의 병존을 기록합니다. 검증 분포의 보고 F1을 외부 공정 성능 또는 통계적으로 유의한 우위로 대체하지 않습니다.

<a id="guide-architecture"></a>

## 구현과 핵심 파일

불변 실행 환경·학습 가중치·제조 원자료가 없는 원고 기반 검토입니다. 모델 명칭이 같아도 구현·입력·선택 정책이 동일한 것은 아닙니다. 구조적 비교와 배포 시스템 검증에 필요한 증거 수준을 나누어 기록합니다.

## LEVEL 5 · 조건과 절차를 상세히 읽기

<a id="semantic-classification-level-5"></a>

### LEVEL 5 · 자료 분할과 세 분류기의 비교

약 2,000장·80:20은 원고 서술의 데이터 규모·분할입니다. 외부 테스트 셋·다 공정 검증이 확인되지 않은 상태에서 F1을 일반화 성능으로 취급하지 않습니다. 정밀도·재현율의 오류 유형과 데이터 범위를 유지해 비교해야 합니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-3-row-1"></a> 약 2,000장 OK/NG·80:20 | OK 는 정상, NG는 불량입니다.<br>사진의 약 80%는 모델이 규칙을 배우는 데, 나머지 약 20%는 그 규칙을 확인하는 데 씁니다.<br>별도 외부 공장 시험을 뜻하지 않습니다. |
| <a id="layout18-table-3-row-2"></a> YOLOv8·ViT·자체 CNN | 세 모델 모두 사진 전체를 정상/불량으로 분류합니다.<br>볼 위치를 찾는 탐지 결과와 구분합니다.<br>금속 표면 흠집·오염의 예시가 모든 결함 종류를 포괄하지는 않습니다. |
| <a id="layout18-table-3-row-3"></a> 정확도·정밀도·재현율·F1 | 정확도는 전체 판정, 정밀 도는 불량으로 지목한 것의 적중, 재현율은 실제 불량을 찾은 정도를 봅니다.<br>F1은 정밀도와 재현율을 함께 요약하지만 오류 종류를 없애지는 않습니다. |


<a id="semantic-models-level-5"></a>

### LEVEL 5 · 입력 크기와 학습 설정의 의미

재현 명세에는 원고의 모델 식별자·전 처리 크기·batch·최대 epoch·patience를 각각 보존해야 합니다. ViT 조기 종료 서술의 상충은 아래 결과 절의 불확실성과 함께 남기며, 공개되지 않은 가중치나 학습 로그를 추정해 채우지 않습니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-4-row-1"></a> YOLOv8 입력 64·batch32 | 입력 크기는 모델에 넣을 사진의 크기 설정, batch32는 한 번의 갱신에 묶는 사진 수입니다.<br>원고 호출의 설정이지 모든 모델의 공통 설정은 아닙니다. |
| <a id="layout18-table-4-row-2"></a> 최대 3,000epoch·patience100 | epoch 는 학습 자료를 반복해 보는 단위입니다. 3,000은 최대 반복 한도이고 patience100은 개선을 기다린 뒤 일찍 멈추는 설정입니다.<br>실제 3,000회를 모두 완료했다는 뜻은 아닙니다. |
| <a id="layout18-table-4-row-3"></a> ViT 224×224·google/vit-base-patch16-224-in21k | 사전 학습된 Vision Transformer를 분류에 이용합니다.<br>YOLO 입력 64와 같게 줄인 사진의 비교가 아닙니다. |
| <a id="layout18-table-4-row-4"></a> 자체 CNN 224×224·합성곱/풀 링 3 블록·완전 연결 층 | 합성곱이 무늬를 찾고 풀 링이 공간 정보를 줄인 뒤 완전 연결층이 분류합니다.<br>원고의 구성 설명이며 실행 패키지가 제공됐다는 뜻은 아닙니다. |


<a id="semantic-cost-level-5"></a>

### LEVEL 5 · F1·속도·용량을 함께 읽기

비교표의 측정 단위와 원고 위치를 고정하고 수치 간 우열을 조건부로 서술합니다. 원자료·로그 부재로 분산·장비별 재현성이 독립 확인되지 않았으며, F1을 백분율 정확도로 다시 명명하지 않습니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-5-row-1"></a> 5 쪽 표·6 쪽 결론의 YOLOv8 | F1 0.972·12ms·약 15MB입니다.<br>F1은 분류 지표, ms는 처리 시간, MB는 모델 크기라 서로 다른 성질을 뜻합니다. |
| <a id="layout18-table-5-row-2"></a> 같은 보고의 ViT | F1 0.958·28ms·약 380MB입니다.<br>더 큰 모델이 이 표에서 더 높은 F1을 얻은 것은 아닙니다. |
| <a id="layout18-table-5-row-3"></a> 같은 보고의 CNN | F1 0.943·22ms·약 4MB입니다.<br>작은 저장 크기와 분류 지표를 함께 비교하되 다른 장비에서도 이 시간이 유지된다고 보장하지 않습니다. |
